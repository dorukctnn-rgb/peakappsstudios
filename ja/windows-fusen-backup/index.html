plum.sqlite と StickyNotes.snt から付箋を読む

古いパソコンやWindows.oldフォルダー、バックアップ用ドライブからWindowsの付箋(Sticky Notes)のファイルをコピーしたのに、付箋が表示されない場合に使います。ファイルを追加すると、メモが色と日時つきでブラウザーに開きます。テキストのコピーも、ファイルとしての保存もできます。アップロードはしません。

  1. 付箋が入っているパソコンで付箋アプリを閉じ、Win + R を押して %LocalAppData%\Packages\Microsoft.MicrosoftStickyNotes_8wekyb3d8bbwe\LocalState を貼り付け、Enterキーを押します。
  2. plum.sqlite と、あれば plum.sqlite-wal と plum.sqlite-shm をコピーします。必ず一緒にコピーしてください。-walファイルに直近の編集が入っています。
  3. Windows 7や初期のWindows 10のパソコンでは、%AppData%\Microsoft\Sticky Notes から StickyNotes.snt をコピーします。

    よくある質問

    ファイルはパソコンの外に出ますか

    いいえ。ページはブラウザーのタブの中でファイルを読み取り、その間は通信を行いません。ページを読み込んだ後はネットワークを切っても動作します。ページに付属するテストでも確認しています。

    なぜ-walファイルも必要ですか

    付箋は新しい編集をまずplum.sqlite-walに書き込み、後でplum.sqliteにまとめます。plum.sqliteだけのコピーでは、最後に書いたメモが欠けることがあります。2つそろえると、SQLiteがデータベースを開くときと同じ方法で、完了した変更を反映します。

    削除したメモを取り戻せますか

    取り戻せる場合があります。Microsoftは、メモの削除は元に戻せないと案内しています。ただ、削除済みメモがしばらくファイルに残ることがあります(削除済みの印がついた行として、または未使用ページに残ったテキストとして)。Proではそこで見つかったものを一覧にします。Windowsやディスクが古いデータを上書きするため、見つかる保証はありません。

    付箋アプリの内容は変わりますか

    いいえ。ファイルを読み取るだけです。メモをアプリに戻す手順はバックアップの場所のガイドにありますが、Microsoftは公式には案内していないため、先に現在のファイルのコピーを取っておいてください。

    Proでは何ができますか

    Proは6ドルの買い切りです。すべてのメモをテキストまたはMarkdownのZIP、CSV、JSON、Macの「メモ」で読み込めるEvernote形式、WordやGoogleドキュメント用ページ、PDFの本として保存でき、見つかった削除済みメモも一覧にします。閲覧・検索・コピーと、5件までのテキスト保存は無料のままです。
