    What stays on your device

    • The files. Read here, in this tab. Nothing is uploaded and no request goes to AO3.
    • The shelf. If Remember my shelf is on, one small record per fic (title, author, tags, counts, file path) sits in this browser's IndexedDB so the shelf is back after a reload. Forget this shelf empties it.
    • Your place. The chapter and scroll position of each fic you read is kept in this browser's local storage.
    • Offline use. After the first visit this page opens without a connection. Chrome and Edge can also remember a folder; Safari and Firefox ask for it again each visit.

    Questions

    Can I read AO3 fics offline?

    Yes, if you downloaded them first. Choose the folder with your EPUB, HTML or PDF files here and read them in your browser. Ficshelf never contacts AO3, so it works while AO3 is down. Reading AO3 fics offline on iPhone, Android and PC

    Does Ficshelf download fics from AO3?

    No. It only opens files you already have. It sends no request to AO3 and hosts no fics. Downloading all your bookmarks: what works

    Which files does it open?

    EPUB and HTML downloads, pages saved from the browser, and ZIP files that hold them. PDFs are listed and open in your browser's own viewer. MOBI and AZW3 are not read: download the EPUB from AO3 instead.

    Are my files uploaded?

    No. The files are read by this page on your own device. If you leave Remember my shelf on, titles and tags (never the files or their text) are kept in this browser so the shelf is back after a reload; Forget empties it. We count page visits with Cloudflare Web Analytics: no cookies, no personal data, and never your files. When you click a Pro button, a counter of our own adds one to a daily total for this tool, with the page and the kind of site that sent you: no cookies, no personal data, no IP address kept, and never your files.

    Will the EPUB it saves work on my Kindle?

    Amazon lists EPUB among the file types Send to Kindle accepts. The EPUB Ficshelf writes has a title, author, language, contents and one file per chapter. AO3 to Kindle, step by step

    Was this tested on real AO3 downloads?

    Not yet. AO3 has been down since October 29, 2026, so Ficshelf was written to the layout AO3 documents for its downloads and tested on files made in that layout. If a real file does not open as it should, write to info@peakappsstudio.com.

    What does Ficshelf Pro add?

    Pro costs $8, paid once. It adds full-text search across the whole library, merging a series or a selection into one EPUB, a tidy ZIP of the whole library, and a catalog as CSV, JSON and a Markdown reading list. Opening, filtering, reading and saving a single fic as EPUB stay free.

    Is Ficshelf made by AO3?

    No. Ficshelf is an independent tool by Peak Apps Studio and is not affiliated with AO3 or the Organization for Transformative Works. AO3 is named only to say which files the tool opens. It does not sell or host fanworks.
