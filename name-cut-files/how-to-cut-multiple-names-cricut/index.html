How to cut multiple names on a Cricut at once

Design Space’s text tool has no list or spreadsheet import, so a batch of names is usually typed, spaced, welded and sized one at a time. There are two ways to cut them in one job: fix each name in Design Space, or make every name at once and upload a single SVG. Both are below, along with what Design Space does to your layout when you press Make It.

Open the name cut file maker The Design Space-only way

Method 1: one SVG with every name

  1. Paste the list. Open the name cut file maker and paste the names one per line, or copy the column from your order spreadsheet.
  2. Choose the font and how to size. Same width makes every name exactly as wide as you type, Same height makes them equally tall, and Fit a box keeps each name inside the same rectangle, which is the right choice when a short name like Mia shouldn’t come out huge.
  3. Check the list under the mat. It shows each name’s finished size and flags any name that would cut into more than one piece. Dots on i and j are always separate.
  4. Download the SVG and upload it. In Design Space choose Upload, then Upload Image, and pick the file. Cricut’s help page says SVG and DXF files “upload as designed”, and a file made with layers arrives as a grouped image that you can ungroup to move each layer on its own. Each name is one layer.
  5. Check one size. Select one name and compare its width and height in the edit bar with the list. They should match to the hundredth of an inch.
  6. Make It. Design Space now lays the names out on the mat itself (see below). For iron-on, turn on Mirror for each mat on the Prepare screen.

Method 2: by hand in Design Space

  1. Paste the list into one text box with a script font, one name per line.
  2. Split it. Use Ungroup to Lines under Format, which Cricut describes as moving “your lines of text into separate text boxes”.
  3. Close the gaps. Lower the Letter Space until the letters overlap. Cricut’s text help says that in fonts from the kerned filter, letters that touch or overlap weld automatically at the cut step. Letters that don’t touch stay separate, so nudge them, ungroup if you must, then select the name and Weld; Weld is permanent.
  4. Size each name. Keep the proportions locked and type the width or height for every name in turn.
  5. Make It, and turn on Mirror for each iron-on mat.

What Design Space does to your layout

When you press Make It, Design Space cuts in material saver mode and places the images “as close together as possible to conserve material”, in Cricut’s words. That ignores the layout you uploaded, which is fine for names: it packs them tightly and you can drag them around on the Prepare screen. If you want the names exactly where they are on the canvas, select them and use Attach, which holds cuts “in the same position relative to each other on the cutting mat as in the Canvas”.

Two limits worth knowing. An uploaded SVG can hold at most 5,000 paths; this tool writes one path per name (two with a backing layer), so that limit only matters past a few thousand names. And Mirror has to be switched on for each mat separately; Design Space can’t mirror several mats at once.

Print Then Cut names

To print the names in colour and have the machine cut around them, upload the SVG as above and change each layer’s operation from Basic Cut to Print Then Cut. The printable area is smaller than the paper because the sensor marks need room. Cricut lists these maximum sizes for the Maker and Explore series:

PaperMaximum verticalMaximum horizontal
Letter, 8.5 × 11 in9.94 in7.44 in
A4, 210 × 297 mm10.62 in7.2 in

The cuttable area isn’t a full rectangle: the corners are kept for the sensor marks, so a design that uses the full height may not get the full width. Pro adds both areas as layout sizes.
