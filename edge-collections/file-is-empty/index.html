Your Edge Collections file is empty or shows only names

An empty collectionsSQLite file, or one that lists collection names with no pages, means Edge did not keep your saved pages on this computer. They may be in another Edge profile, on another computer, in Bing Saves if you used a personal Microsoft account, or in Favorites if you clicked "Move to Favorites". Before anything else, close Edge and copy the whole Collections folder, and do not sign out or clear browsing data first.

Last checked: October 28, 2026, against Microsoft's own help pages. Not affiliated with Microsoft.

Where your pages can be, in order

  1. Another Edge profile on this PC. Collections belong to the profile where you made them. Look in the Profile 1 and Profile 2 folders next to Default. Which profile is which shows how to tell.
  2. Another computer. The file holds what Edge kept on the computer it is on. If you mostly used Collections on a different PC, copy the folder from there.
  3. Bing Saves. Microsoft says "only MSA users can see their previously saved collections at https://bing.com/saves", where MSA means a personal Microsoft account (Organize your ideas with Collections in Microsoft Edge). A work or school account will not show anything there. If the page will not open, see Bing Saves not working.
  4. Favorites. If you clicked "Move to Favorites" when Edge offered it, each collection is a folder in your Favorites now. Only the pages moved: Microsoft says "Images, notes, and other non-page items aren't included" (Organize your ideas with Collections in Microsoft Edge).
  5. An earlier version of the file. A Microsoft support specialist answered a user whose collections vanished after syncing (August 2023) that "If you haven't previously synced your data, it may not be possible to retrieve it", and suggested checking whether the Collections database has previous versions to restore (lost collections in edge after syncing (August 24, 2023)). In File Explorer, right-click the Collections folder, choose Properties and look for a Previous Versions tab. It only has entries if Windows kept restore points or File History was on, so an empty tab is common. A backup program that includes your AppData folder is the other place to look.
  6. Your IT team, if the account is a work or school one. Microsoft offered "Export Your Data" to those accounts in Edge versions that still showed the Collections pane (Organize your ideas with Collections in Microsoft Edge).

What not to do first

Do not sign out of Edge, clear browsing data, reset the profile or delete the profile folder until you have copied the Collections folder. The accepted answer in an older Microsoft Q&A thread (April 2023) copies the Collections folder to a new profile first, and only then signs out and clears the device's data (My collections have disappeared, how do I recover them? (February 12, 2023)). Without that copy, those steps would remove what the PC holds. Work on a copy, and keep the original untouched.

Many people are in the same place. The Microsoft Q&A thread "How do I recover all of my Collections in Microsoft Edge?" (June 2026) is tagged "Same question" by more than 80 people (How do I recover all of my Collections in Microsoft Edge? (June 5, 2026)). If the pages are in none of the places above, Microsoft lists no way to bring them back.

Questions

Why does Stashback say my Collections file is empty?

Either you picked the empty helper file collectionsSQLite-journal, or the database has no collections in it because Edge kept nothing on this computer. Check the other profile folders and Bing Saves.

Edge kept only the names of my collections. Where are the pages?

Online. Microsoft says personal Microsoft accounts can see their previously saved collections at bing.com/saves. Stashback lists the names so you know what to look for there.

Can I get Edge Collections back?

Not the Collections pane: Microsoft removed it in Edge 149. Your saved pages can still be in another profile, another computer, Bing Saves or Favorites, and Stashback saves what the file holds as bookmarks.
