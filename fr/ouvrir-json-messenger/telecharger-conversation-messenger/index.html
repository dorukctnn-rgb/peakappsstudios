Télécharger une conversation Messenger et l’enregistrer en PDF

Pour télécharger une conversation Messenger, la sauvegarder ou l’enregistrer en PDF, il faut passer par l’export de vos informations chez Meta. Il livre vos messages en fichiers JSON, et les conversations chiffrées de bout en bout se téléchargent à part. Voici les étapes, ce que contient le fichier, et ce qu’aucun téléchargement ne peut récupérer.

Ouvrir votre téléchargement dans Readback

Ce que Messenger vous donne, et par où passer

Un téléchargement complet de vos conversations Messenger passe par la demande d’export de Meta. Elle livre vos messages dans un ZIP, un dossier par conversation, en fichiers JSON. Les conversations chiffrées de bout en bout n’y sont pas : elles ont leur propre téléchargement.

Télécharger vos conversations Messenger, étape par étape

  1. Sur Facebook, cliquez sur votre photo de profil, puis sur Paramètres et confidentialité et Paramètres. Ouvrez le Compte Meta, c’est-à-dire l’Espace Comptes, puis Vos informations et autorisations.
  2. Cliquez sur Exporter vos informations (l’outil s’appelle aussi Télécharger vos informations), puis sur Créer une exportation, et choisissez votre profil Facebook.
  3. Choisissez l’export vers votre appareil, puis les messages comme type d’informations, toute la période et le format JSON. Pour garder les photos et les vidéos, ne limitez ni la période ni la qualité des médias.
  4. Cliquez sur Démarrer l’exportation. Meta prépare le fichier et vous prévient par e-mail. Téléchargez chaque partie ZIP proposée, sous Téléchargements disponibles : le lien ne reste actif que quelques jours.

Les conversations chiffrées de bout en bout se téléchargent à part

Meta ne peut pas lire sur ses serveurs les messages chiffrés de bout en bout, donc l’export ordinaire ne peut pas les contenir. Dans le ZIP de Facebook, les conversations concernées sont sous messages/e2ee_cutover, avec leur historique jusqu’au passage au chiffrement. La suite est conservée dans votre stockage sécurisé, protégé par votre code PIN ou une autre méthode, et Messenger vous laisse la télécharger séparément.

  1. Utilisez un ordinateur : l’aide de Meta décrit ce téléchargement sur le web, pas dans l’application.
  2. Ouvrez vos discussions sur le web. messenger.com ne sert plus aux messages depuis avril 2026 et renvoie vers facebook.com/messages.
  3. Selon la version, l’option est dans les options de vos discussions, sous Historique des discussions, Dernière sauvegarde, avec le bouton Télécharger la sauvegarde des discussions. Elle peut aussi se trouver sous Confidentialité et sécurité, Discussions chiffrées de bout en bout, puis Stockage des messages, avec le téléchargement de vos données de stockage sécurisé.
  4. Saisissez votre mot de passe ou votre code PIN si Messenger le demande, et gardez la page ouverte pendant que le fichier se prépare, ce qui peut prendre plusieurs minutes. Le résultat est un ZIP avec un fichier Nom_N.json par conversation et un dossier media.

Les intitulés changent d’une version à l’autre : cherchez Stockage des messages ou Historique des discussions si les vôtres diffèrent.

Lire le fichier : où sont vos conversations

Dans le ZIP de Facebook, les messages sont sous your_facebook_activity/messages/ (sous messages/ à la racine dans les anciens téléchargements). Chaque dossier est une conversation (nom de la personne ou du groupe, puis un numéro, par exemple luciafernandez_10158). Les dossiers inbox, message_requests, archived_threads et filtered_threads séparent vos conversations, les demandes jamais acceptées, vos archives et les demandes filtrées comme spam probable. Photos, vidéos et messages vocaux sont dans les dossiers photos, videos et audio.

Une longue conversation est coupée en plusieurs fichiers. message_1.json contient les messages les plus récents, et dans chaque fichier le plus récent vient en premier.

Enregistrer une conversation Messenger en PDF, sans l’envoyer sur un site

Un convertisseur en ligne reçoit vos conversations sur ses serveurs. Un navigateur suffit pour s’en passer.

  1. Ouvrez votre téléchargement dans Readback : le ZIP, le dossier décompressé ou les fichiers message_1.json.
  2. Choisissez la conversation, puis réglez “Vos messages sont de” sur votre nom pour que vos messages soient à droite.
  3. Cliquez sur Imprimer cette conversation. Readback met en page toute la conversation, du premier message au dernier, avec ses photos.
  4. Dans la fenêtre d’impression, choisissez Enregistrer au format PDF comme imprimante, et activez les graphiques d’arrière-plan dans les paramètres supplémentaires pour garder le bleu de vos messages.

Les vidéos et les messages vocaux ne tiennent pas sur papier : le PDF les nomme à l’endroit où ils ont été envoyés. Une conversation de dizaines de milliers de messages donne un PDF de centaines de pages, alors cherchez d’abord la partie qui vous intéresse, puis imprimez seulement ces pages.

Messages supprimés ou annulés : ce que le fichier ne contient pas

Le téléchargement contient les messages tels qu’ils existent dans votre compte au moment de la demande. Un message supprimé avant n’y est généralement pas, et aucun outil ne peut sortir d’un fichier ce qu’il ne contient pas. Quand l’expéditeur a annulé l’envoi d’un message, le téléchargement en garde parfois un repère, sans le texte : Readback l’affiche comme “Message annulé”.

Retrouver ses conversations chiffrées sur un nouvel appareil

Pour les discussions chiffrées de bout en bout, Messenger les restaure avec votre code PIN, un compte Apple (iOS), un compte Google (Android), un code à 40 caractères ou un code à usage unique. Après décembre 2026, la clé enregistrée dans Google Drive ne donnera plus accès à l’historique sur un nouvel appareil : Messenger demandera de créer un code PIN à la place. Si vous comptez changer de téléphone, créez ce code avant, et gardez aussi une copie téléchargée de vos conversations chiffrées.

Questions

Comment télécharger une conversation Messenger sur PC ?

Sur ordinateur, ouvrez l’Espace Comptes, Vos informations et autorisations, Exporter vos informations, puis créez une exportation vers votre appareil avec les messages et le format JSON. Meta vous écrit quand le ZIP est prêt. Les conversations chiffrées de bout en bout se téléchargent à part, et seulement sur ordinateur : suivez les étapes du guide ci-dessus.

Comment sauvegarder ou enregistrer une conversation Messenger en PDF ?

Ouvrez votre téléchargement dans Readback, choisissez la conversation, cliquez sur Imprimer cette conversation, puis choisissez Enregistrer au format PDF dans la fenêtre d’impression. Tout se passe dans votre navigateur : rien n’est envoyé à un serveur.

Peut-on télécharger ou récupérer une conversation Messenger supprimée ?

Non. Un message supprimé avant votre demande n’est généralement pas dans le téléchargement. Pour un message dont l’envoi a été annulé, le fichier garde parfois seulement un repère, que Readback affiche comme “Message annulé”. Aucun outil ne peut recréer le texte.

Pourquoi mes conversations les plus récentes manquent-elles dans le téléchargement ?

Elles sont probablement passées au chiffrement de bout en bout, et l’export ordinaire s’arrête à ce passage. Téléchargez aussi vos conversations chiffrées et choisissez les deux téléchargements ensemble dans Readback : chaque conversation devient une seule chronologie.

Comment récupérer une conversation Messenger sur un nouvel appareil ?

Les discussions chiffrées de bout en bout se restaurent avec votre code PIN, un compte Apple ou Google, un code à 40 caractères ou un code à usage unique, selon ce que vous avez configuré. Le téléchargement n’est pas une restauration : c’est une copie à lire, que vous gardez vous-même.

Readback envoie-t-il mes conversations quelque part ?

Non. La page lit les fichiers sur votre ordinateur, et fermer l’onglet les efface. Les convertisseurs qui demandent de déposer le ZIP sur leur site, eux, reçoivent vos conversations.
