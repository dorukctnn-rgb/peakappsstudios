Publisher Save As and Export greyed out: how to get your file out

If Publisher still opens your .pub file but Save As, Export and copy and paste are greyed out, your file is still on your disk. Microsoft says Microsoft 365 subscribers can no longer open or edit Publisher files in Publisher once it is removed, and the answers in the Microsoft Q&A reports below say a Microsoft 365 copy cannot be switched back on. Microsoft does not describe the greyed-out state itself. Get the file out another way: a PC with a perpetual Publisher, LibreOffice Draw, or Unframe, which reads the .pub file itself.

Last checked: October 28, 2026, against Microsoft's own pages and the sources listed at the end. Not affiliated with Microsoft.

What people are seeing

Microsoft’s retirement page says that Microsoft 365 subscribers “will no longer be able to open or edit Publisher files in Publisher” (Microsoft Publisher will no longer be supported after October 2026). It says nothing about commands going grey. Public Microsoft Q&A threads show it, one after another:

The answers in these threads point the same way. Where the Publisher came with Microsoft 365, one says reactivating may not restore the disabled commands; another says there is no supported way to restore that edition. Those answers come from community answerers, not from Microsoft’s Publisher team, so read them as the best reading of the notice and not as a fix.

Check which Publisher you have

In Publisher, open File, then Account, and read the product name and whether it is activated. This is where the answers start, because Microsoft’s FAQ treats the two kinds differently (Microsoft Publisher will no longer be supported after October 2026):

  • Publisher from Microsoft 365: “will no longer be available for installation or download after October 2026”, and subscribers can no longer open or edit Publisher files in it. Microsoft’s Message Center post calls access on a PC that still has it “a temporary window to open and convert impacted .pub files” (Reminder that support ends in October 2026).
  • Perpetual Publisher (the one in Office LTSC 2021 and Consumer Office 2021): support ended October 13, 2026, but you “will still be able to install and use the app beyond this date”. A perpetual copy that says unlicensed looks like an activation problem to take to Microsoft support, not a problem with your file.

Do this first, whichever route you take

  1. Find every .pub file and copy it to a separate folder or a drive. Microsoft’s advice is to search your PC, OneDrive and SharePoint for “.pub” (Microsoft Publisher will no longer be supported after October 2026).
  2. Work on the copies. One answer adds that renaming a .pub file does not convert it.
  3. Try Export once. One answer says File, Export, Create PDF/XPS Document works when Save As is greyed out. The person with 131 files reported Export greyed out too, so do not count on it.
  4. Keep the originals, even after you have a PDF or a Word file.

Questions

Why are Save As and Export greyed out in Publisher?

Microsoft does not explain this state. Reports from October 18 to 26, 2026 show it together with an activation or unlicensed message, and Microsoft says subscribers can no longer open or edit Publisher files in Publisher once it is removed.

Is my .pub file damaged?

Nothing in Microsoft’s notice or in these reports says so. Microsoft says the files stay where they are; what goes is the program that opens them.

Can I get Publisher back on Microsoft 365?

Microsoft says it is no longer available for installation or download for subscribers after October 2026. A perpetual Publisher, as in Office 2021, can still be installed and used even though its support ended on October 13.

Which Publisher files can Unframe read?

Files saved by Publisher 2002 and later. It was tested on files saved by Publisher 2003, 2007, 2010 and 2013. Files from Publisher 2016, 2019, 2021 and Microsoft 365 are expected to be the same kind, but none was available to test. Publisher 98 and 2000 files are not read.
