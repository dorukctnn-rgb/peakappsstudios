plum.sqlite, StickyNotes.snt에서 스티커 메모 읽기

예전 PC나 Windows.old 폴더, 백업 드라이브에서 스티커 메모(Sticky Notes) 파일을 복사했는데 Windows에서 메모가 보이지 않을 때 사용합니다. 파일을 추가하면 메모가 색과 날짜와 함께 브라우저에 열립니다. 글을 복사하거나 파일로 저장할 수 있습니다. 업로드하지 않습니다.

읽는 파일
plum.sqlite(Windows 10, 11)와 plum.sqlite-wal, StickyNotes.snt(Windows 7과 초기 Windows 10)
저장 위치
내 컴퓨터 안에서만 처리합니다. 업로드가 없고 페이지를 불러온 뒤에는 오프라인에서도 작동합니다
비용
읽기, 검색, 복사는 무료입니다. Pro는 6달러 한 번 결제입니다

1파일 추가하기

plum.sqlite, plum.sqlite-wal, StickyNotes.snt를 여기에 끌어 놓으세요

또는

이 파일들은 어디에 있나요
  1. 메모가 있는 PC에서 스티커 메모를 닫고 Win + R을 누른 뒤 %LocalAppData%\Packages\Microsoft.MicrosoftStickyNotes_8wekyb3d8bbwe\LocalState 를 붙여 넣고 Enter를 누르세요.
  2. plum.sqlite와, 있다면 plum.sqlite-wal, plum.sqlite-shm을 복사하세요. 함께 복사해야 합니다. -wal 파일에 가장 최근 편집이 들어 있습니다.
  3. Windows 7이나 초기 Windows 10 PC라면 %AppData%\Microsoft\Sticky Notes 에서 StickyNotes.snt를 복사하세요.

파일이 없다면 샘플 메모로 결과가 어떻게 보이는지 확인할 수 있습니다.

파일은 이 탭 안에서만 읽습니다. 업로드하지 않으며 메모 내용은 브라우저에 저장되지 않습니다. 페이지 방문 수는 Cloudflare Web Analytics로 셉니다. 쿠키도 개인 데이터도 쓰지 않으며 내 파일에는 손대지 않습니다. Pro 버튼을 누르면 자체 카운터가 이 도구의 일일 합계에 1을 더합니다. 기록하는 것은 페이지와 어떤 종류의 사이트에서 왔는지뿐입니다. 쿠키도 개인 데이터도 쓰지 않고 IP 주소도 저장하지 않으며 내 파일에는 손대지 않습니다.

    자주 묻는 질문

    파일이 내 컴퓨터 밖으로 나가나요

    아니요. 페이지는 브라우저 탭 안에서 파일을 읽으며 그동안 어떤 요청도 보내지 않습니다. 페이지를 불러온 뒤에는 네트워크를 꺼도 작동합니다. 페이지와 함께 제공되는 테스트로도 확인합니다.

    왜 -wal 파일도 필요한가요

    스티커 메모는 새 편집을 먼저 plum.sqlite-wal에 쓰고 나중에 plum.sqlite로 합칩니다. plum.sqlite만 복사하면 마지막에 쓴 메모가 빠질 수 있습니다. 두 파일이 있으면 SQLite가 데이터베이스를 열 때처럼 완료된 변경을 반영합니다.

    삭제한 메모를 되살릴 수 있나요

    가끔 가능합니다. Microsoft는 메모 삭제가 영구적이라고 안내합니다. 그래도 삭제된 메모가 한동안 파일에 남을 수 있습니다(삭제 표시된 행으로, 또는 사용하지 않는 페이지에 남은 글로). Pro는 거기서 찾은 것을 목록으로 보여 줍니다. Windows와 디스크가 오래된 데이터를 덮어쓰므로 찾을 수 있다고 약속하지는 않습니다.

    내 스티커 메모가 바뀌나요

    아니요. 파일을 읽기만 합니다. 메모를 앱에 되돌리는 방법은 백업 위치 안내에 있지만 Microsoft가 공식적으로 안내하는 단계는 아니므로 먼저 현재 파일을 복사해 두세요.

    Pro는 무엇을 더해 주나요

    Pro는 6달러 한 번 결제입니다. 모든 메모를 텍스트 또는 Markdown ZIP, CSV, JSON, Mac 메모 앱이 가져올 수 있는 Evernote 파일, Word와 Google 문서용 페이지, PDF 책으로 저장하고 찾은 삭제된 메모도 목록으로 보여 줍니다. 읽기, 검색, 복사와 5개까지 텍스트 저장은 계속 무료입니다.

    Peelback은 Peak Apps Studio가 만들었으며 Microsoft와 관련이 없습니다. Sticky Notes는 Microsoft의 제품입니다.
