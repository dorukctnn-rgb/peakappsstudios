How it works

  1. Open the layered PDF. Use the copy-shop or the home-printer file, whichever you'd print. The tool lists the pattern's layers by name, with each size's line style beside it.
  2. Keep your size and the notes. Untick the sizes you don't need. Leave layers like notes, labels or the test square on. Tick two sizes if you grade between them.
  3. Download the copy and print it. The other sizes are removed from the drawing, so Preview, an iPad, Chrome or any printer driver can only print what you kept.

Why the other sizes still print

A layered pattern stores every size in one file and marks each size as an optional layer. Adobe Acrobat Reader on a computer has a Layers panel to switch them off. Most other apps don't: Mac Preview draws every layer, Acrobat Reader on iPad and Android has no layer controls, and the viewer built into Chrome shows whatever the designer left switched on.

This tool doesn't rely on the app. It writes a new PDF in which the sizes you untick are taken out of the page drawing, so there is nothing left for any app to show. Lines, text and the page size stay exactly as the designer made them.

Good to know

What changes in the file. Inside each page, the drawing for a switched-off layer is removed while everything that positions the rest (clipping, text placement) is kept, which matches how Acrobat hides a layer. Page boxes are untouched, so a 1 inch test square stays 1 inch. The layers you kept are still listed as layers if you open the copy in Acrobat.

Protected PDFs. Pattern files with a print-allowed password lock can't be edited as lines, so the copy is made from high-resolution page images instead: 300 dpi for home-printer pages, 200 dpi for large sheets. If the designer has turned printing off, the tool won't make a copy.

Your rights. Use it with patterns you've bought or downloaded for your own sewing, the same way you'd print them. Check the designer's terms before sharing or selling anything made from a copy.

Questions

Is my pattern uploaded anywhere?

No. Your browser opens and rewrites the PDF on your own device. The file is never sent to us or anyone else, and closing the tab discards it. See privacy and licenses.

Will the pattern still print at the right size?

Yes. The copy keeps every page at exactly its original size and nothing is scaled. Print it at 100% or Actual size and measure the test square before printing all the pages. Printer settings for each app.

Why does my PDF show no layers?

The file isn't layered. Some designers sell a separate PDF for each size, or flatten every size onto one layer. Check your download for a file called "layered", or ask the designer. Without layers the sizes can't be separated, but Pro can still tile a large sheet onto home-printer pages.

Can I print two sizes to grade between them?

Yes. Tick both sizes, for example one for the bust and one for the waist, and the copy will contain both outlines and nothing else you switched off.

Does it work on an iPad or a Chromebook?

Yes, in Safari or Chrome. Open the PDF from Files or Downloads, choose your size and download the copy. On an iPad, print it from the share sheet and check the test square, because iPadOS has no Actual size setting. iPad printing guide.

My PDF is password-protected. Will it work?

If the designer's settings allow printing, the tool makes the copy as high-resolution page images (300 dpi for home-printer pages, 200 dpi for large sheets) instead of lines. If printing is switched off for the file, the tool won't make a copy.

What does Pro add?

Pro is a one-time 9 US dollar purchase. It tiles A0 and copy-shop sheets onto A4 or US Letter pages with trim lines, page labels, neighbour labels, optional overlap and an assembly map with test squares, and it makes projector files with light lines on a black background and thicker lines.
