¿Dónde están estos archivos?
  1. En el PC que tiene las notas, cierra Notas rápidas, pulsa Win + R, pega %LocalAppData%\Packages\Microsoft.MicrosoftStickyNotes_8wekyb3d8bbwe\LocalState y pulsa Intro.
  2. Copia plum.sqlite y, si existen, plum.sqlite-wal y plum.sqlite-shm. Cópialos juntos: el archivo -wal guarda las últimas ediciones.
  3. En un PC con Windows 7 o con las primeras versiones de Windows 10, copia StickyNotes.snt desde %AppData%\Microsoft\Sticky Notes.

    Preguntas

    ¿Mi archivo sale de mi ordenador?

    No. La página lee el archivo en la pestaña del navegador y no hace ninguna petición mientras tanto. Además funciona sin conexión cuando la página ya cargó. Las pruebas que acompañan a la página lo comprueban.

    ¿Por qué pide también el archivo -wal?

    Notas rápidas escribe las ediciones nuevas primero en plum.sqlite-wal y las pasa a plum.sqlite más tarde. Una copia de plum.sqlite sola puede perder las últimas notas. Con los dos archivos, la página aplica los cambios terminados como hace SQLite al abrir una base de datos.

    ¿Puede recuperar una nota que borré?

    A veces. Microsoft indica que borrar una nota es permanente. Una nota borrada puede seguir un tiempo en el archivo, como fila marcada como borrada o como texto en páginas sin usar. Pro enumera lo que encuentra. No se promete nada: Windows y el disco sobrescriben datos viejos.

    ¿Cambia mis Notas rápidas?

    No. Los archivos solo se leen. Para devolver las notas a la aplicación, mira la guía sobre la ubicación de la copia; Microsoft no documenta ese paso, así que guarda antes una copia de los archivos actuales.
