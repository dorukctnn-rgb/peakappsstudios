Move Samsung Pass to 1Password

1Password imports from Chrome and from Bitwarden, not from Samsung Pass. Decant opens the .spass file in the browser, so you can bring your logins in as a Chrome file.

The way in is the Chrome import

1Password’s support site has an import page for each source. Samsung Pass is not among them; Chrome and Safari are, and both take a CSV of logins. Decant’s Google and Chrome file is that kind of file.

Move the logins

  1. Open the .spass file in Decant, type the export password and choose Google and Chrome file.
  2. Import it. In the 1Password desktop app choose File > Import, pick Chrome and select the CSV file.
  3. Delete the CSV and the .spass file after you have checked a few items, and empty the trash.

Why the Chrome file and not the Bitwarden file

1Password reads a Bitwarden export only in Bitwarden’s encrypted JSON form, according to its help page. The Pro file that Decant writes is the unencrypted kind, the one Bitwarden and KeePassXC import, so it does not go into 1Password. The Chrome CSV is the shared language here: 1Password reads it, and so do the others. If you use 1Password and also want your cards and addresses kept, print the Pro sheet and add them by hand, or keep the Bitwarden file in a safe place until you have.

Questions

What does 1Password import from Chrome?

1Password’s Chrome import takes the CSV that Chrome exports, which holds passwords and nothing else. Decant’s Google and Chrome file has the same columns.

Can 1Password read the Bitwarden file?

1Password’s help page for importing from Bitwarden says it reads the encrypted JSON export of Bitwarden. The Pro file from Decant is unencrypted Bitwarden JSON, so the Chrome CSV is the way into 1Password.

Where are my cards?

Not in the Chrome CSV. Decant lists them and Pro writes them on a printable sheet; you can add a card to 1Password by hand from it.

Is the file uploaded?

No. Decant decrypts and converts in your browser and has no connection that could send the file.
