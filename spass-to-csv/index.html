Open a .spass file: Samsung Pass to CSV, Apple Passwords or Bitwarden

Samsung Pass exports an encrypted .spass file that no other password manager reads. Decant opens it in your browser with the export password you chose, and writes the file your next manager imports. The file and the password stay on this page.

    Where do I find the .spass file?
    1. Open Samsung Pass on the Galaxy phone. On newer phones it sits inside Samsung Wallet.
    2. Open its settings and choose Export data (some versions say Import and export). Menu names differ by phone and app version.
    3. Select what to export (logins, cards, addresses, notes) and set an export password. Write it down: it is asked once and it is not stored in the file.
    4. The file is saved on the phone, usually in Downloads, and ends in .spass. Copy it to this device, or open this page on the phone.

        The order Decant uses to list your logins

        1. E-mail and account recovery. Your inbox can reset almost every other password.
        2. Money. Banks, cards, payments, investing, tax.
        3. Phone and the big accounts. Your carrier, Apple, Google, Microsoft, Amazon.
        4. Work and files, then social and messages, then everything else.

        Inside each group, a password used on several logins comes first, then logins that have a one-time code. Each login links to the site’s /.well-known/change-password page (a W3C convention) and to its home page.

        What happens to your file

        • The file is read and decrypted inside this page with Web Crypto, the encryption built into your browser: PBKDF2 with SHA-256 and 70,000 rounds makes the key from your export password, and AES-256-CBC opens the data.
        • Reading a file makes no network request. The page makes requests only for its own files and, if you open the Pro panel, for Paddle’s checkout. You can load the page, switch off Wi-Fi and use it offline.
        • The password is held in memory while the file opens and the box is emptied after. Nothing from your file is stored. The change list keeps only a scrambled key per login you tick, in this browser.
        • To check it yourself, open your browser’s network panel and then open a file: you will see no request.

        Questions

        Is my .spass file or password uploaded anywhere?

        No. Decant decrypts the file inside this page and writes the new files in the same place. Its code makes no request with your file or your password, and you can load the page, switch off Wi-Fi and use it offline.

        Which password does it ask for?

        The export password you typed in Samsung Pass when you exported. It is not your Samsung account password, not your screen lock and not stored in the file. If you lost it, the file cannot be opened; export again from Samsung Pass and write the new password down.

        Why not import the .spass file straight into Apple Passwords or Bitwarden?

        Neither reads it. The file is encrypted and Samsung offers no other export format; Apple takes a CSV with column names, and Bitwarden has no Samsung Pass importer. Decant makes the CSV.

        What happens to the logins of Android apps?

        They keep their name, username and password. An iPhone or a Mac cannot use the app itself, so Decant fills in the website of well-known apps such as Instagram or Netflix and marks every app login. Those without a known website stay on the change list and in the Bitwarden file.

        How is this different from the scripts and apps on GitHub?

        Several open-source converters exist: scripts for Python and Go, an Android app, and a browser page that writes a Chrome CSV with logins only. Decant opens the file in the browser, also writes Apple Passwords and Bitwarden files, keeps cards, addresses, notes and one-time codes, and lists the logins in the order to change them.
