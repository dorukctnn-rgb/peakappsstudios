Where are these files?
  1. On the PC that has the notes, close Sticky Notes, press Win + R, paste %LocalAppData%\Packages\Microsoft.MicrosoftStickyNotes_8wekyb3d8bbwe\LocalState and press Enter.
  2. Copy plum.sqlite and, when they are there, plum.sqlite-wal and plum.sqlite-shm. Copy them together: the -wal file holds the latest edits.
  3. From a Windows 7 or early Windows 10 PC, copy StickyNotes.snt from %AppData%\Microsoft\Sticky Notes.

    Questions

    Does my file leave my computer?

    No. The page reads the file in your browser tab and makes no request while it does. It also works with the network switched off once the page has loaded. The tests shipped with the page check this.

    Why does it ask for the -wal file too?

    Sticky Notes writes new edits to plum.sqlite-wal first and merges them into plum.sqlite later. A copy of plum.sqlite alone can miss the last notes you wrote. With both files, the page applies the finished changes the way SQLite does when it opens a database.

    Can it bring back a note I deleted?

    Sometimes. Microsoft says that deleting a note is permanent. A deleted note can still sit in the file for a while, as a row marked deleted or as text left in unused pages. Pro lists what it finds there. Nothing is promised: Windows and the disk overwrite old data.

    Does it change my Sticky Notes?

    No. The files are only read. To put notes back into the app, see the guide to the backup location; Microsoft does not document that step, so keep a copy of the current files first.
