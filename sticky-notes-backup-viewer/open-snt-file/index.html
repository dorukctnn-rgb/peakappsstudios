How to open StickyNotes.snt, the old Sticky Notes file

Windows 7, Windows 8 and the first Windows 10 releases kept every Sticky Note in one file called StickyNotes.snt. Nothing on a newer Windows opens it, but the notes are still readable.

Checked 5 November 2026

Where the file is

On the PC that has the notes, the file sits in %AppData%\Microsoft\Sticky Notes. Copy it before you reinstall or reset the PC.

What is inside

StickyNotes.snt is a Microsoft compound file, the same container older Office documents use. Each note is a storage named after a GUID, cut to the 31 characters a compound file allows. Inside, stream 0 holds the note as RTF and stream 3 holds a plain text copy that StickyParser found cut short on long notes, so Peelback reads stream 0 first. The storage's own dates are the note's created and changed times. The Forensics Wiki adds that a deleted note's streams are removed from the file.

Open it with Peelback

  1. Copy StickyNotes.snt to a folder you can reach.
  2. Drop it on the tool page. Each note opens as text with its dates.
  3. Copy a note, or save the first five as a text file. Pro saves them all as text files, Markdown, CSV and more.

Peelback does not read note colours from .snt files, so those notes show in yellow.

Other ways to read it

The Forensics Wiki points to the MiTec Structured Storage Viewer, a Windows program that lists the streams of a compound file. StickyParser, a Python script, writes the notes of a .snt file to a CSV file. Both ask you to install something. A website that asks you to upload the file sends your notes to someone else's server.

Have the file? Open it here: nothing is uploaded. Open plum.sqlite or StickyNotes.snt

Questions

Why is every note yellow?

The page reads the text and the dates from a .snt file. It does not read colours from it, so it shows them all in yellow.

Can Word open StickyNotes.snt?

No. The file is a container with one RTF stream per note, not a document. Open it in Peelback and save the notes as text, or as a Word page with Pro.
