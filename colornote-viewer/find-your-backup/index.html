Where your ColorNote backup is, and how to get it onto a PC

ColorNote keeps its backups on the phone and lets you send each one from the app. Make a backup, send the .backup file to yourself, then open it on the computer with the password you set. These steps follow ColorNote's own help pages.

1. Make a backup on the phone

  1. Open ColorNote, open the menu and tap Backup, then the Device tab. You can also get there from Settings, Backup.
  2. Tap Backup notes. If you use a master password, ColorNote asks for it; the backup is locked with that password.
  3. The new backup appears in the list on the same screen.

2. Send it to your computer

Tap the backup file in that list and send it to yourself: by email, Google Drive or another app on the phone. ColorNote's help page describes exactly this way of moving a backup to another device. On the computer, download the file from the email or the drive.

Copying with a USB cable instead? Older versions of ColorNote kept backups in a folder named data/colornote/backup on the phone's storage, according to users' reports. Newer Android versions keep an app's files in its own storage, which a cable often cannot see, so sending the file from the app is the reliable way.

3. Check it is the right file

FileWhat it is
Ends in .backup, for example colornote-20260128.backupA device backup from a current version of ColorNote. This is the one to open.
Ends in .dat or .docA backup from an older version of ColorNote. Notelift tries these too.
Ends in .zipA backup that a mail app or cloud drive packed into a ZIP. Notelift opens the backup inside.
colornote.dbColorNote's working database, not a backup. Make a backup in the app instead.

4. The password

Every ColorNote backup is encrypted. If you never set a master password, ColorNote uses 0000, and Notelift tries it first, so the backup simply opens. If you did set one, type the master password you had when the backup was made.

Forgot it? ColorNote's help says a device backup made with a forgotten master password may not be recoverable, and points to its automatic backups, which do not need the master password unless "Secured auto backup" was turned on. Those open with 0000.

5. Open it

Go to the ColorNote backup viewer, choose the file and, if asked, type the password. The file is opened in your browser on this device: nothing is uploaded.
