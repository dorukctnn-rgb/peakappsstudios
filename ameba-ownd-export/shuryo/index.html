Ameba Ownd のサービス終了：いつまでに、何をするか

Ameba Ownd は2026年12月24日（木）11:00 にサービスを終了します。その後はサイトの閲覧も書き出しもできず、データの復元もできません。運営の発表（11月2日と5日）をもとに、日付と、今のうちにやることをまとめました。

決まっている日付

Ameba Ownd の終了までの予定（運営の発表、2026年11月5日確認）
日時内容
2026年10月22日（木）システムに脆弱性が見つかり、緊急メンテナンスを開始
2026年11月2日（月）13:00サイトの閲覧のみ再開。記事やページの投稿・更新はできない。プレミアムプランの課金を停止
2026年11月中エクスポート機能の提供開始（管理画面へのログイン、コンテンツのエクスポート、サイトの削除のみ）
2026年12月24日（木）11:00サービス終了。エクスポート機能も終了し、閲覧もできなくなる
2026年12月中プレミアムプランの返金を完了（申し込みは不要）

11月5日の説明では、運営は移行期間の延長を検討中としています。延長が決まっても、上の日付で準備しておけば間に合います。

今やること

  1. 今の内容を保存する。投稿も編集もできない状態のまま終了日が来ます。公式のエクスポートは「11月中」で日付が決まっていないため、先に記事と画像を手元に置いておくと安心です。方法はエクスポートを待たずに保存する方法にまとめました。
  2. 移行先を決める。運営が挙げている移行先は Amebaブログと WordPress です。独自ドメインを使い続けたい場合、Amebaブログは独自ドメインに対応していないため、WordPress などを選びます。WordPress への手順はWordPress へ移行する手順にあります。
  3. 独自ドメインの設定を変える（使っている人だけ）。12月24日 11:00 までに、ドメイン管理会社で CNAME レコード（custom-domain.amebaowndme.com）を移行先の設定に変えます。独自ドメインの移し方を参照してください。
  4. ショップ機能を使っている人は BASE の設定を確認する。運営によると、連携済みの BASE アカウントでショップは続けられます。BASE の管理画面「設定」>「ショップ情報」で「カート機能のみを使用」のチェックを外し、「ショップ公開状況」が「公開する」になっているかを確かめます。
  5. 返金は待つだけ。月間プランは10月1日以降の支払いを全額、年間プランは条件に応じて全額か月割りで、12月中に支払ったカードへ返金されます。

なぜ終わるのか

運営の説明では、10月22日に対応が必要な脆弱性が見つかり、長期にわたって安全性を保ちながら提供を続けるのは難しいと判断した、とされています。同じ説明で、この脆弱性を使った不正アクセスや個人情報の流出は「現時点で確認されていない」こと、Amebaブログなど他の Ameba のサービスは別のシステムで動いていることも書かれています。

終了前に、今の内容を保存しておく。Utsushi はサイトのアドレスを入れるだけで新しい記事30件を読み込み、ブックマーク1つで全記事とページを集めます。WordPress 用ファイルは無料です。

よくある質問

Ameba Ownd はいつまで見られますか？

2026年12月24日（木）11:00 までです。それ以降はサイトの閲覧もエクスポートもできず、データの復元もできないと運営は発表しています。11月5日の時点で、移行期間の延長が検討されています。

今は記事を更新できますか？

できません。11月2日 13:00 からは閲覧のみで、記事やページの投稿・更新は止められています。旧サイトに新しいアドレスを書いて知らせることも、今はできません。

amebaownd.com のアドレスは新しいサイトに引き継げますか？

引き継げません。amebaownd.com などのアドレスは運営のドメインなので、終了後に転送することもできません。独自ドメインを使っている場合は、DNS を変えれば同じアドレスで新しいサイトを公開できます。

プレミアムプランの返金は申し込みが必要ですか？

不要です。運営がプレミアムプランを解約し、12月中に支払ったクレジットカードへ返金します。カードの期限切れなどで返金できない場合は、個別に案内があるとされています。
