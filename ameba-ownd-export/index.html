Ameba Ownd のサイトを保存して、WordPress に移す

Ameba Ownd は2026年12月24日（木）11:00 に終了し、その後はサイトの閲覧も書き出しもできなくなります。Utsushi なら公式のエクスポートを待たずに、記事・ページ・画像を今日保存できます。

期終了は2026年12月24日（木）11:00運営は延長を検討中としています（11月5日）

サイトを読み込む

いちばん簡単なのは1です。記事が30件より多いサイトは、2で全部集められます。

  1. 1アドレスを入れる新しい記事30件

    amebaownd.com、themedia.jp などのアドレスも、独自ドメインも使えます。サイトのフィード（rss.xml）から本文と画像を読み込みます。

  2. 2全部集めるパソコン

    下のボタンをブックマークバーにドラッグします。自分の Ameba Ownd のサイトを開いて、そのブックマークを押すと、全記事とページが1つのファイル（utsushi-…json）になってダウンロードフォルダに保存されます。

    Utsushi で集める

    ドラッグできないとき
    1. 「コードをコピー」を押します。
    2. ブックマークバーを右クリックして「ページを追加」（Chrome、Edge）または「ブックマークを追加」（Firefox）を選びます。Safari では、どこかのページをブックマークしてから「編集」を選びます。
    3. 名前に「Utsushi で集める」、URL にコピーしたコードを貼り付けて保存します。
    4. Ctrl+Shift+B（Mac は command+shift+B）でブックマークバーを表示できます。

    このブックマークは、押したサイトのページだけを読み、ほかのどこにも送信しません。中身は collect.js で読めます。

  3. 3ファイルを開く

    集めたファイル（.json）、ブラウザで保存したページ（.html）、rss.xml、それらをまとめた ZIP をここにドロップ。

読み込んだ記事と画像はこのブラウザの中だけで扱い、Peak Apps のサーバーには送りません。通信するのは、あなたのサイトのフィードと、画像を表示・保存するときの Ameba Ownd の画像サーバーだけです。 ページの閲覧数は Cloudflare Web Analytics で数えています。Cookie も個人データも使わず、あなたのファイルには触れません。 Pro ボタンを押すと、自前のカウンターがこのツールの1日の合計に1を加えます。記録するのはページと、どの種類のサイトから来たかだけです。Cookie も個人データも使わず、IP アドレスも保存せず、あなたのファイルには触れません。

      WordPress に移すまで

      1. 保存する。上で読み込み、「WordPress 用ファイルを保存」を押します。
      2. 読み込む。WordPress の「ツール」>「インポート」>「WordPress」で、保存した wordpress.xml を選びます。「添付ファイルをダウンロードしてインポートする」にチェックを入れると、画像も Ameba Ownd から取り込みます（12月24日 11:00 まで）。
      3. アドレスを合わせる。独自ドメインなら、パーマリンクを /posts/%post_id%/ にすると記事のアドレスが Ameba Ownd と同じになります。

      よくある質問

      公式のエクスポートと何が違いますか？

      公式のエクスポートは2026年11月中に提供予定で、形式はまだ発表されていません（11月5日時点）。Utsushi は今日から使え、保存した内容を WordPress がそのまま読み込めるファイルにします。両方を使うのがいちばん確実です。

      読み込んだ記事はどこかに送られますか？

      送られません。記事、ページ、画像はこのブラウザの中だけで扱います。通信するのは、あなたのサイトのフィード（rss.xml）と、Ameba Ownd の画像サーバー（画像を表示・保存するとき）だけです。

      スマホでも使えますか？

      サイトのアドレスを入れる方法（新しい記事30件）と、ファイルを開く方法はスマホでも使えます。全記事を集めるブックマークはパソコンのブラウザ向けです。

      Amebaブログに移せますか？

      運営は移行先として Amebaブログを挙げていますが、11月5日の時点でファイルから取り込む方法は発表されていません。Amebaブログは独自ドメインに対応していないため、独自ドメインを使い続けるなら WordPress などを選びます。

      画像は12月24日以降も残りますか？

      残らないと考えてください。画像は Ameba Ownd の画像サーバーにあり、終了後は表示されなくなります。WordPress に取り込むか、Pro で ZIP にして手元に保存しておきます。

      Utsushi は Ameba Ownd の公式ツールですか？

      いいえ。Peak Apps Studio が作った独立したツールで、Ameba Ownd（株式会社サイバーエージェント）とは関係ありません。

      Utsushi Pro では何が増えますか？

      8ドル（買い切り）で、全記事と全ページの WordPress 用ファイル、すべての画像の ZIP（200 MB ごと）、ネットなしで開けるサイトの写し、Markdown、独自ドメイン用の転送設定を一度に保存できます。記事を読む、1件ずつ保存する、新しい記事30件とページ3件の WordPress 用ファイル、画像の一覧は無料です。
