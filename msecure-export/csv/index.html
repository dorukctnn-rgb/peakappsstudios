Export mSecure to a CSV file

mSecure writes your vault to a CSV file from its desktop apps. The phone apps cannot. Here are the steps, and what is inside the file you get.

Checked November 5, 2026

On a Mac

  1. Open mSecure and enter your master password.
  2. Open the File menu, choose Export, then CSV.
  3. Name the file, choose the export options and click Export.

On Windows

  1. Open mSecure and enter your master password.
  2. Click the gear-shaped Settings icon, then Backups.
  3. Choose the option to export data to a CSV file. The Windows app exports the current view or the selected records, so start from All Items.

On iPhone, iPad and Android

There is no CSV export in the iOS app (mSecure support, in its forum). The help article lists Mac and Windows steps only. If mSecure is only on your phone, install mSecure for Mac or Windows, sign in so the vault syncs, and export from there.

What is in the file

One record per line, with no header row. The first four columns are the record name with mSecure’s ID after a |, the record type (Login, Credit Card, Email Account, Bank Account, Note and the others), the tag and the note. Then come the fields, each as label, type number and value:

Gmail|410001,Login,Personal,,Website|2|https://accounts.google.com,Username|7|alex@gmail.com,Password|8|...

The numbers come from Bitwarden’s open-source mSecure importer and its test files; mSecure does not publish them. A | inside a value is written twice (||), and line breaks in notes may appear as \n.

Where to take it next

Apple Passwords (needs the columns rewritten), Bitwarden (imports it directly; Rekey keeps more of it), 1Password (through its Chrome importer). After the November 2026 notice, also plan the password changes.

Questions

Can I export mSecure from my iPhone?

No. mSecure’s support replied in its forum that there is no way to export to CSV in the iOS version and that the Mac and Windows versions can. Install mSecure on a Mac or Windows PC, let it sync, and export there.

Why does the Windows export miss records?

mSecure’s help says the Windows app exports the current view or the selected records. Go to All Items (or select everything) before you export.

Is the CSV encrypted?

No. mSecure warns that exported CSV files are not encrypted and are stored in plain text: do not e-mail them or store them online, and delete them when you are done.

Why does every value have a | in it?

mSecure writes each field as label|type|value, for example Password|8|.... Other apps do not read that layout, which is why Apple Passwords refuses the file. Rekey reads it and writes the layouts other managers use.

I have mSecure 4 or older. Does it work?

Older exports put the values without labels (Web Logins rows with the website, username and password in order). Rekey reads those rows by position and names the other values Field 1, Field 2 and so on, so check them after the import.
