        Questions

        Is my password file uploaded anywhere?

        No. Rekey reads the CSV inside this page and writes the new files in the same place. The page cannot send your file: its code makes no request with it, and you can load the page, switch off Wi-Fi and use it offline. The checklist keeps only a scrambled key per login and your ticks in this browser, never a name or a password.

        Which mSecure versions work?

        The CSV from mSecure 5 and 6 for Mac and Windows (File > Export > CSV on a Mac, Settings > Backups on Windows). Older exports from mSecure 3.5 and 4 open too; their unlabeled values are read by position. The phone apps cannot export CSV.

        Why not import the CSV straight into Apple Passwords?

        Passwords needs a row of column names and plain values. The mSecure file has no header row and writes each field as label|number|value, so Passwords answers that the file is missing column labels. Rekey writes the columns Passwords uses.

        Does moving to a new manager make me safe?

        Not by itself: the passwords you import are the same ones mSecure stored. After mSecure’s notice of November 3, 2026, change them, starting with e-mail and money. Rekey gives you that order and the change page of each site.
